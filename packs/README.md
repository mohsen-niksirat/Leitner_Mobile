## 📝 ساختار هر کلمه

هر فایل JSON شامل آرایه‌ای از کلمات با این ساختار است:

```json
{
  "word": "achieve",
  "translation": "رسیدن به، دست یافتن",
  "ipa": "/əˈtʃiːv/",
  "partOfSpeech": "verb",
  "example": "She achieved her goal of band 8.",
  "definitions": ["to succeed in reaching a goal"]
}
```

## 📥 نحوه وارد کردن

### روش ۱: از داخل اپ
1. به بخش **ابزارها** بروید
2. روی **📥 وارد کردن بسته لغت** کلیک کنید
3. فایل JSON مورد نظر را انتخاب کنید

### روش ۲: کپی متن
1. فایل JSON را باز کنید
2. محتوای آن را کپی کنید
3. در بخش **افزودن دسته‌ای** بچسبانید

## 🏷️ دسته‌بندی‌ها

- **آزمون‌ها:** IELTS، TOEFL، GRE
- **تخصصی:** کامپیوتر، پزشکی، بیزنس
- **عمومی:** مکالمه روزمره، آکادمیک

## ⭐ کلمات هر بسته شامل:

- ✅ کلمه انگلیسی
- ✅ ترجمه فارسی
- ✅ تلفظ (IPA)
- ✅ نوع کلمه (اسم، فعل، صفت، ...)
- ✅ مثال انگلیسی
- ✅ تعریف انگلیسی
